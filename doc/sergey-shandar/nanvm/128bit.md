# 128bit VM for high-level languages

128-bit VM is designed for languages where we can't create NaN-based tag-pointers in 64-bits. The idea is to have enum (1 byte) and 15 bytes payload.
For example:

```rust
enum {
    Null,
    Undefined,
    Number(f64),
    Bool(bool),
    String(Rc<String16>),
    Bigint(Rc<Bigint>),
    Object(Rc<Object>),
    Array(Rc<Array>),
    Function(Rc<Function>),

    StaticString16(&'static StaticString),
    StaticAscii(&'static StaticAscii),
    StaticBigint(&'static StaticBigint),
    StaticObject(&'static StaticObject),
    StaticArray(&'static StaticArray),
    StaticFunction(&'static StaticFunction),

    ShortString16([u16;7]), // for some languages that don't support sized-arrays it can be u64, or a tuple (u32, u32, u32)
    ShortAscii([u8;14]), // for some languages that don't support sized-arrays it can be u64, or a tuple (u32, u32, u32)
    ShortBigint(i64),
}
```
