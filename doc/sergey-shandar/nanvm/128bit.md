# 128bit VM for high-level languages

128-bit VM is designed for languages where we can't create tag-pointers. The idea is to have enum (1 byte) and 15 bytes payload.
For example:

```rust
enum {
    Null,
    Undefined,
    Number(f64),
    Bool(bool),
    String(Rc<String16>),
    Bigint(Rc<Bigint>),
    Object(Rc<Object>),
    Array(Rc<Array>),
    StaticString16(&'static [u16]), // it can create more than 128 bit structure
    StaticAscii(&'static[u8]), // it can create more than 128 bit structure
    ShortString16(u8, [u16;7]),
    ShortAscii(u8, [u8;14]),
    ShortBigint(i64),
}
```
