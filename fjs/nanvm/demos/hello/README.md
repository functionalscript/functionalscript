# Hello, World

The smallest FunctionalScript program: it writes `hello, world` to standard
output. The demo below runs it as JavaScript and as WebAssembly, and shows
what each run wrote and how long it took. The program spells its bytes as a
`bigint`, since `fjs compile` cannot compile `fjs/types/bit_vec` yet.

See [WASM demos](../README.md) for the other pages.
