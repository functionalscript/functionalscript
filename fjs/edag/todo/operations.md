# Operations

|             |                  |
|-------------|------------------|
| `a.b`       | `['.', a, b]`    |
| `a(...b)`   | `['()', a, b]`   |
| `a?.b`      | `['?.', a, b]`   |
| `a?.(...b)` | `['?.()', a, b]` |

## Combinations

HCF is a hidden control flow.

|                         |                          |HCF |
|-------------------------|--------------------------|----|
| `a.b.c`                 | `['.', ['.', a, b], c]`  |    |
| `a.b(...c)`             | `['()', ['.', a, b], c]` |this|
| `const x = a.b;x(...c)` | `['()', ['.', a, b], c]` |    |
