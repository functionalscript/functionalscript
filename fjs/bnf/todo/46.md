## 46. Implement an LR(1) parser.

**Priority:** P3
**Status:** open

Implement an LR(1) parser because LL(1) can't handle break lines in comments.

The parser targets the current BNF: functional form in
[../module.f.ts](../module.f.ts), serializable form in
[../data/module.f.ts](../data/module.f.ts). It needs an AST structure derived
from that BNF definition — see
[parser-structure](./parser-structure.md) for the AST shape.
