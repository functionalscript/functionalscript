## Integrate Deno documentation with the site theme

**Priority:** P3
**Status:** open

Match the Deno documentation's colours, typography and spacing to the
FunctionalScript design system. Improve the visual integration of Deno's
sidebar, search and navigation, including responsive behaviour on mobile and
consistent dark and light themes.

Preserve the official Deno documentation navigation, search, JavaScript and
internal links. Avoid a custom documentation renderer. This work is visual;
signature and source-link correctness remains in `deno-doc-rendering.md`.
