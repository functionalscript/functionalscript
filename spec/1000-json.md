# JSON

JSON forms a tree of values.

```json
{
    "a": null,
    "b": [-42.5, false, "hello"]
}
```

File extension: `.json`.

A JSON document is a valid FunctionalScript module: JSON is a subset of
FunctionalScript. The one exception is a document containing a `__proto__`
key, which JSON reads as an ordinary data key and JavaScript does not
([proto-property-key](./2480-proto-property-key.md)).

The command format for streaming JSON values into the VM is a design
document: [vm-command-format](./todo/vm-command-format.md).
