- `fjs`: every authored FunctionalScript file is `.f.js`. All remaining
  `module.f.mjs`, `demo.f.mjs`, `testlib.f.mjs`, `sample.f.mjs` and proof
  paths change extension, `fjs/module.f.mjs` included; no `.f.mjs` file
  ships. (#3755, #3816, #3888, #3926, #3938, #3943, #3985)
- `compiler`: admit array and object rest destructuring. `[head, ...tail]`
  lowers to `slice`; `{ a, ...rest }` copies the remaining own enumerable
  string entries. Rest initializers and rest-parameter patterns remain
  refused. (#3800, #3843)
- `compiler`: unary `+` compiles with JavaScript ToNumber semantics,
  throwing on a BigInt, and `a[+x]` is admitted as a numeric index.
  (#3982)
- `compiler`: admit `Boolean(value)` as a conversion operator; detached,
  constructor, guarded, spread and multiple-argument forms are refused.
  `Number.MAX_VALUE`, `Number.MIN_VALUE` and `Number.MIN_SAFE_INTEGER`
  lower to their values. (#3760, #3923, #3945)
- `runtime`: admit `Math.trunc`, `floor`, `abs`, `sqrt`, `ceil`, `imul`,
  `max`, `min` and `clz32` natively, and `Math.log2`, `fround` and `round`
  through shared FunctionalScript bodies. `Math` becomes a reserved
  global. (#3765, #3792, #3794, #3796, #3797, #3913, #3942)
- `runtime`: admit `Object.keys`, `Object.values` and the global
  `encodeURIComponent`, which throws on an unpaired surrogate. A module
  can no longer bind or shadow `encodeURIComponent`. (#3752, #3848, #3923)
- `runtime`: array `map` and array and string `concat` run one authored
  FunctionalScript body shared by the interpreters and NaNVM; the native
  implementations are removed. (#3750, #3773)
- `types/ref_map`: add the reference map, `empty`, keyed by object
  identity: `m(key)` reads and `m(key, value)` sets, each answering the
  value and a map. The compiler, both EDAG interpreters and NaNVM run it.
  (#3810, #3812, #3814, #3815, #3826, #3827, #3828)
- `compiler`: deeply nested patterns, parameters and loops no longer
  overflow the host stack, and a standalone block in a function body no
  longer crashes the parser. Serialized JavaScript keeps an object shared
  with a self-reading function's capture single. (#3819, #3926, #3944)
- `types/map`, `types/set`: both become persistent insertion-ordered
  collections without native `Map` or `Set`. `types/map` adds `empty`,
  `mapGet`, `mapHas`, `mapEntries`, `fromEntries` and `size`; `types/set`
  adds `fromValues`, and `values` keeps insertion order. (#3854, #3885)
- `types/object`: `at` is removed in favour of `entry`, which answers
  `undefined` rather than `null` on absence. Add `types/object/name` with
  `nameOf` and `types/object/size` with `size`, a value's node count as a
  tree. (#3774, #3943, #3947, #3970)
- `types/bit_vec`, `types/prime_field`: the `lsb` and `msb` member `concat`
  becomes `concatVec`, and `PrimeField`'s `sub` becomes `subtract`.
  (#3778, #3783)
- `types/number`: add `fromBits` and `fromBits32`; `bitsOf` moves here from
  `media/rust`. (#3806, #3911)
- `media/json`: add `toJson`, serializing keys in the value's own order,
  and `stringifyIndented(indent)`. The serializer's `codec` and
  `treeSerialize` take an optional indent. (#3906, #3950)
- `text/percent`: add `encodeUriComponent`, JavaScript's
  `encodeURIComponent` over any value, keeping `!'()*` unescaped. The RFC
  3986 encoders are unchanged. (#3884, #3923)
- `ebnf`: add `reference()` and `define(reference)(body)` for recursive
  rules; `toData`, the LL(1) `parser` and `byteParser` take optional
  definitions. Eleven `compiler/parser/grammar` rules become references,
  resolved through its new `definitions` export. (#3921)
- `ebnf/data`, `rtti`: generated rule IDs and recursive labels no longer
  come from JavaScript function names. EBNF IDs follow a rule's structural
  path; RTTI labels, TypeScript aliases and JSON Schema definition names
  are ordinal. (#3860, #3861)
- `media/datajs/serializer`: assume a FunctionalScript value. Property
  descriptors, prototypes, symbol keys, sparse arrays and cycles are no
  longer checked; functions are still refused at any depth. (#3874)
- `effects/node`: add `capture`, running a literal argv with closed input
  and returning its status, stdout and stderr, and
  `availableParallelism`. `NodeOp` gains both operations. (#3742, #3744)
- `effects/node/virtual`: reading a virtual JS module throws a one-element
  array holding the diagnostic rather than an `Error`; virtual fetch
  answers "not found" for prototype-like names. (#3832, #3847)
- `effects/mock`, `effects/memory`: `runAll` and `partialRun` handlers may
  take the active runner as a second argument. `MemoryState.values`
  becomes `slots`. (#3791, #3830, #3974)
- `types/uint8array`: the host module moves from `module.f.mjs` to
  `module.mjs`. (#3846)
- `compiler`, `edag`, `types/btree`: helpers move out of demos and proofs
  into `compiler/compiled`, `compiler/edag/graph`, `types/btree/structure`
  and `edag/from_fast/control_flow`. The `Evaluator` type requires
  `moduleArgs`. (#3938)
- `ir`: add a typed code IR in progress, with `check`, `print`, `lifetime`
  and a WASM emitter, L0 and native interfaces with JavaScript hosts, and
  `from_fast`, lowering normalized FAST including loops, records, throws
  and calls. (#3806, #3807, #3808, #3813, #3824, #3837, #3856, #3865, #3870, #3871, #3887, #3890, #3896, #3897, #3898, #3908, #3918, #3922, #3929, #3932, #3935, #3936)
- `wasm/runtime/l0`: `buildArray` and `buildObject` call their callbacks in
  the order of one loop, so `at` runs before `next`. Results are
  unchanged; only which callback's throw surfaces differs. (#3903)
- `nanvm`: `Number` gains `trunc`, `floor`, `abs`, `sqrt`, `ceil`, `imul`,
  `max`, `min` and `clz32`; `From<f64>` normalizes NaN. `IComplex` requires
  `address`, and `vm::unstable` adds `ref_map`. (#3792, #3794, #3796, #3797, #3827, #3942)
- `nanvm`: `toLowerCase` and `toUpperCase` follow Unicode 18.0.0 Default
  Case Conversion, previously 17.0.0. (#3925)
- `emergent_testing`: `fjs cov node` runs coverage children in parallel,
  bounded by available CPUs, replays a failed child's output and reports
  real time, processor time and concurrency. Cache hits print no line.
  (#3738, #3742, #3743, #3744, #3745)
- `emergent_testing`: `fjs cov node` fails a module whose source the
  dependency parser rejects, and measures `demo.f.js`. A test expects a
  throw only under a `throw` key, not from an inferred function name.
  (#3740, #3860, #3938)
- `compiler`: `fjs compile` links each module once across a run rather
  than once per file. (#3938)
- `ci`: the generated workflow gains a `package` job that tests the packed
  tarball outside the checkout, and runs the host JavaScript tests on ARM
  only. `ciJobs`, `packageJobId` and `nodeVersionJobs` change; `ci` adds
  `writeWorkflows`. (#3735, #3746, #3938)
- `website/playground/btree`: an Undo button takes back the last move that
  changed the tree, counted as a move. (#3720)
- `website`: railroad pages name nested grammar states, and RTTI demo
  schemas show the real module filename in displayed imports.
  (#3858, #3894)
