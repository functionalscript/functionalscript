- `edag`: new module — an rtti schema for expression-DAG nodes: primitives,
  arrays, objects, `args`, and the recursive `propertyAccessor`, `call`, and
  `propertyCall` forms.
- `types/rtti/ts`: new `Check<A, B>` type — `Assert<Check<A, typeof schema>>`
  pins a hand-written type against what an rtti schema actually derives to.
