- **BREAKING CHANGES:** `path`: `..` can no longer escape an absolute path's
  root — `parse('/..')` is `[]` where it was `['..']` — and `normalize` and
  `concat` keep that root, so `fjs compile` accepts an absolute module path
- **BREAKING CHANGES:** `path`: a Windows `C:/` is a root too, so `..` cannot
  climb off the drive — `normalize('C:/..')` is `'C:/'` where it was `''`
- **BREAKING CHANGES:** `path`: `concat` no longer anchors a bare drive —
  `concat('C:')('dir')` is the drive-relative `C:dir` where it was `C:/dir`
- **BREAKING CHANGES:** `path`: an absolute right-hand side to `concat`
  replaces the left instead of being appended to it
- `path`: new `root` reports a path's root — `'/'`, `'//'`, `'C:/'`, or `''`
- `path`: new `escapes` answers whether a `..` climbs above a path's root, which
  `parse` cannot — it folds with the root in place, so the escaping `..` is what
  it removes. `fjs/web` refuses a request path with it
