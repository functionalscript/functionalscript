- **BREAKING CHANGES:** `djs`: `{ __proto__: v }` and `{ "__proto__": v }`
  are compilation errors in a FunctionalScript module; the key is written
  `{ ["__proto__"]: v }`, which is also what the module emitter now produces
- `djs`: computed property keys `{ ["a"]: 1 }` with a constant string key
- `djs`: `fjs compile` picks its input's language by extension the way it
  already picks its output's — a `.json` input is a JSON document, where
  `"__proto__"` is an ordinary data key, so it compiles to
  `{["__proto__"]:…}` and back. Only the file named on the command line: an
  imported file is read as a FunctionalScript module until the language has
  `with { type: "json" }`. New `parser` export `parseJsonFromTokens`
