- `effects/node`: `IoChannel` names the standard IO error channel
  (`NotImplemented | IoError`), which was spelled out 51 times across 50 lines. `IoResult<T>`
  is now `Result<T, IoChannel>`. Same type throughout — an IO-touching effect
  says it fails the way node IO fails, so gaining a new way to do so no longer
  walks up every enclosing signature.
- **BREAKING CHANGES:** `cas/evo`: `Evo.add` and `Evo.revision` no longer nest a
  domain `Result` inside the effect's value. Both answer
  `Effect<…, T, EvoChannel>`, where `EvoChannel` is the new tagged `EvoError`
  or `NotImplemented`. A rejected revision now short-circuits `step` like any
  other failure, and `evoSummary` renders either case.
- **BREAKING CHANGES:** `effects/io`: `unwrapStep` takes a second argument, a
  `summary` for the channel it panics on. It was generic in the error type, so
  it compiled however far a channel widened and quietly enlarged what it
  crashed on; a renderer written for one channel does not accept a wider one,
  so that is now a compile error at the site that chose to panic. `errorSummary`
  is the renderer for the node channel.
- **BREAKING CHANGES:** `effects/node`: a `Program` answers
  `Effect<O, 0, number>` rather than `RawEffect<O, number>` — `ok(0)` for
  success, `error(n)` for failure. A bare number could not say which codes meant
  failure, so nothing short-circuited on one and a continuation that dropped a
  failure and answered `0` type-checked. `errorExit` is
  `Effect<Write, never, number>`; the new `exitCode` reads the code from either
  branch.
- `djs/transpiler`: the five `ParseError`-valued signatures say
  `Effect<ReadFile, T, ParseError>` rather than the equivalent
  `RawEffect<ReadFile, Result<T, ParseError>>`. Same type; #1640 rewrote the
  rule that decides between the spellings but merged before that commit landed,
  so both arrive here.
- **BREAKING CHANGES:** `effects/list`: a `List` cell can fail.
  `List<O, T, E> = Effect<O, Next<O, T, E>, E>`, so a producer that cannot
  deliver fails the stream instead of yielding an error *item* followed by a
  tail nobody pulls. `Cas.read` is `(hash) => List<O, Vec, IoChannel>`. Six
  consumers hand-rolled the same short-circuit because the failure sat in `T`,
  where a generic combinator could not see it; `step` does it now.
