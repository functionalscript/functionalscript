  a nested lock map, to any depth, so `LockMap` values read as
  `string | LockMap` and need narrowing. Every flat map stays valid, and the
  `vnd.fjs.revision` dialect is unchanged. The schema export `_lock` is now
  `lock`

  at every depth, preserving nested scopes
- `mcp/evo`: `evo_add` accepts and advertises `lock`, reusing the media
  format's recursive schema
