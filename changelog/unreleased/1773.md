- **BREAKING CHANGES:** `fjs/ci/nix`: generated flakes move from
  `nix/generated/<job>/` to `nix/<job>/`, so `generatedDirectory` is now `nix`.
- **BREAKING CHANGES:** `fjs/ci/nix`: `nixDevelopAll` and `nixVersionCheckStep`
  are removed, with the `nix-flakes` CI job. A flake is checked by the job that
  uses it, and what it declares is asserted by proofs.
- `ci`: the Node 24 and Node 26 jobs run their commands through their generated
  Nix flakes, one step each, instead of installing Node with `setup-node`. Node
  26 runs `npm run ci-update` and its drift check last, after every other
  command. Every Ubuntu Node job checks its runtime version first.
- `ci`: the `node26` job no longer greps `.mjs` files for a file-scope
  `@typedef`. The rule stands; a text pattern cannot answer a question about
  scope, so it approximated one as indentation.
