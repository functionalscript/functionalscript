- **BREAKING CHANGES:** `types/rtti/common`'s `Visitor<R>` gains a required
  `close` handler, so an external implementer has to add one. Both in-repo
  implementers, `validate` and `parse`, are updated.
- `types/rtti`: new `close(c, rest?)` schema — a closed container, admitting
  the members `c` declares and, with a `rest`, any number of members belonging
  to it. Structs and tuples on their own stay open.
- `types/rtti/ts`: `printer` and `dataToTs` render an object pattern with an
  empty `rest` as its fields alone — `{}` rather than
  `{readonly[k in string]?:never}`, which said the opposite of what an empty
  `rest` means.
- `types/rtti/data`: `toData` keeps a declared key whose set is the whole value
  domain when the pattern also has a `rest`; dropping it there widened the set.
