- `ci`: `fjs ci` writes `dev.sh` at the repository root — `nix develop ./nix`,
  the interactive counterpart to `nix/run`. It carries no flags and takes no
  arguments, so a first entry shows what it is fetching.
- `ci`: that `dev.sh` carries a generated-by marker and `fjs ci` reads before it
  writes, so a consuming project's own `dev.sh` is left alone with a note on
  `stderr` rather than truncated.
