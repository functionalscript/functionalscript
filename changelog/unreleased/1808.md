- `ci`: the four non-Windows platform jobs run `cargo` and this repository's
  suite inside the shared Nix shell instead of installing a toolchain per
  runner. They are the only place the shell's `x86_64-linux`,
  `aarch64-darwin` and `x86_64-darwin` outputs are built rather than generated
  as text. Only the two Windows jobs still
  install a toolchain, because Nix has no native Windows.
- `ci`: those three jobs no longer install a published FunctionalScript and run
  `fjs test`; they run this commit's suite through `node --test`, as `deno` and
  `bun` already did. The published-CLI check survives on the two Windows jobs.
- `ci`: `rust/module.f.mjs` exports `i686Target`, the predicate deciding which
  platform jobs a shared shell cannot serve, and `rustPlatformCommands`, the
  native checks as commands rather than steps.
- **BREAKING CHANGES:** `media/nix`: an `_IndentedString` is its parts rather
  than one string — `['indented-string', ...(string | _Reference)[]]`. A string
  part is escaped as before; a `_Reference` part is written `${a.b}` for Nix to
  resolve, which is the only way a generated hook can name a store path.
  `NixJob`'s `shellHook` takes the same parts.
- **BREAKING CHANGES:** `ci`: the `apt-get` `MetaStep` variant is removed. Its
  one producer installed a 32-bit libc for `ubuntu-intel`, which now gets one
  from its flake, and no generated job asks the runner for a system package any
  more.
- `ci`: `ubuntu-intel32` is a new job, and the 32-bit Linux checks moved to it
  from `ubuntu-intel`. Its flake's `shellHook` points `cargo` at
  `pkgsi686Linux.stdenv.cc`, which is marked broken on every other system the
  shared shell serves and so cannot live there; it replaces
  `apt-get install libc6-dev-i386`, which a Nix toolchain could not have seen.
  The two jobs now run in parallel, and every platform job enters one shell.
- `ci`: a `nodeExtra` step injected into a non-Windows platform job runs inside
  the shared Nix shell, alongside that job's own commands. Those jobs no longer
  install Node with `setup-node`, so a step left on the runner would find
  whatever the image ships. `install` steps and steps naming an action stay on
  the runner — the first runs before the checkout the flake lives in, and the
  second has no command to wrap.
- `media/nix`: adjacent string parts of an `_IndentedString` are escaped as one
  literal. Escaping them separately let a reserved sequence be synthesised
  across the boundary: `['$', '{x}']` emitted an interpolation, and `["a'",
  "'b"]` closed the string and produced invalid Nix.
