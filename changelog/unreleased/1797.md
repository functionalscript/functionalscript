- `djs`: a lexical error that knows how far the offending source runs carries an
  optional `end` position, and a compile error renders it as a span —
  `path:line:column-column` within one line, `path:line:column-line:column`
  across several. An unterminated string or comment now reports both where it
  opened and where the input ran out; a grammar failure still prints the point
  form. `ErrorToken` and `ParseError` gain the optional field; existing
  consumers that ignore it are unaffected.
