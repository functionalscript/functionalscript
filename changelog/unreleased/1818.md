- **BREAKING CHANGES:** `emergent_testing`: `startBrowserTestSources` no longer
  takes an importer — a page's `import()` is an operation its interpreter
  answers, so the argument is gone and `_BrowserImporter` with it
- `effects`: `errorMessage` moved from `effects/node` to `effects`, beside the
  channel it renders. `effects/node` re-exports it
- `emergent_testing`: the browser page loads its proof modules one at a time.
  The walk is a sequential fold over the sources, so the page's interpreter no
  longer implements `all`, and a suite larger than the engine's call-argument
  limit is not a shape the runner can build
