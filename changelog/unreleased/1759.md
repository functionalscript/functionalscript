- **BREAKING CHANGES:** `edag`: a chain ends by **arity**, not by a `null`
  terminator. A plain property read is `['.', a, 'b']`, a terminal call step
  is `['|()', c]`, and `['|!()', c]` closes a region — each one element
  shorter than before, with the continuation operand present only where a
  chain actually continues. Every kind that can end is now an `or` of its two
  closed arities, so `null` is a primitive again and has no reading in a
  continuation position: graphs written against the old spelling
  (`['.', a, 'b', null]`, `['|()', c, null]`) no longer validate, and the
  `Dot`, `OptionDot`, `OptionCall`, `PropertyLambda`, `OptionLambda` and
  `OptionPropertyLambda` types no longer admit them. Closedness by length is
  what keeps a continuation from being smuggled onto a terminal, which is
  what the explicit `null` used to guard; a trailing hole matches neither
  arity and is rejected as before. `amnesia` reads a continuation by
  destructuring everywhere, `skip` included, so an absent one never reaches
  the prototype.
