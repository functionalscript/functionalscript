- **BREAKING CHANGES:** `djs`: `{ __proto__: v }` and `{ "__proto__": v }`
  are compilation errors in a FunctionalScript module; the key is written
  `{ ["__proto__"]: v }`, which is also what the module emitter now produces
- `djs`: computed property keys `{ ["a"]: 1 }` with a constant string key
- `djs`: `fjs compile` picks the input language by extension the way it
  already picks the output one — a `.json` input is a JSON document, where
  `"__proto__"` is an ordinary data key, so it compiles to
  `{["__proto__"]:…}` and back. New `parser` export `parseJsonFromTokens`
