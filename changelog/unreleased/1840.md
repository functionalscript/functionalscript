- `emergent_testing`: the browser page renders a row for a test **while it is
  running** — its name, `data-status="running"` — and settles that same row
  when the test lands, so a proof that blocks no longer blocks with nothing on
  screen
- `emergent_testing`: `runBrowserProofs` takes an optional third argument,
  `start`, called with a test's `TestId` before the test runs. The run yields a
  macrotask after it, so a page that renders from it gets the paint. Existing
  calls are unaffected
