- **BREAKING CHANGES:** `bnf/ll1`: the AST converges with `bnf/descent`'s — the
  AST a `RuleSet` implies is now one contract across backends. A rule is entered
  *before* its first symbol is consumed, so every rule invocation owns a node:
  a sequence's leading item keeps its node, a nullable item that matched empty
  leaves an empty node, a taken variant tags the branch's own node, grouping
  survives (`[[A, B], C]` and `[A, B, C]` are distinguishable), and a `Repeat`
  is matched iteratively into one flat node instead of a right-recursive chain.
  `dispatchMap` now stores per-rule first sets with variant branch selection
  instead of consumed-symbol rule chains, and throws `left recursion …` at
  build time for a grammar that is left-recursive — previously such a grammar
  built silently. `AstTag` narrows to `string | undefined`: `true`-tagged nodes
  no longer occur. The `descentDivergence` proof group becomes
  `descentEquivalence` — same grammar, same pinned AST, matched by both
  backends
