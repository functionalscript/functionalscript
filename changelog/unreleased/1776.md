- **BREAKING CHANGES:** `nanvm`: the shared operator corpus reuses the
  canonical EDAG operation ids and runs the expression each case denotes. `Op`
  is gone — a group carries an `Op1Id` or an `Op2Id`; `Case` takes the operand
  count that id fixes, so a bare `Case` no longer resolves; and `rust`'s `call`
  gives way to `nodeExpr`.
