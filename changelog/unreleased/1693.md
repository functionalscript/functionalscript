- **BREAKING CHANGES:** `effects/node`: `Listen` takes the host to bind —
  `listen(server, port, host)` — and answers an `IoResult`, so a bind failure
  reaches the program instead of killing the process
- **BREAKING CHANGES:** `effects/node`: `FileStat` carries `isFile` beside
  `size`, so a caller can refuse to read a FIFO or a device — a read that
  reaches one never returns
- `web`: new `fjs web [root] [port]` command serving a directory over HTTP on
  `127.0.0.1`, with `index.html` for a directory path and `Content-Type` by
  extension
- `web`: it refuses dotfiles, non-regular entries, a `Host` it does not answer
  for, userinfo in an authority or a port that is not a number below 65536, and
  a scheme that is not `http` or `https`
- `web`: percent escapes decode in linear time rather than quadratic — 5,000 in
  one target, about the most a request line can carry, took 101 ms of event loop
  and now take 43
- `effects/node`: an over-cap request body is `413` and a listener that throws
  is `500`, both closing the connection; either used to end the server process
- `effects/node`: a request body of many small chunks is read in linear time —
  20,000 one-byte chunks took 2.8 seconds and now take 0.17
- `effects/node`: a `listen` that fails removes its handlers, so a retry loop
  leaks none
- `effects/node/virtual`: `createServer` and `listen` are implemented, reporting
  `ERR_SOCKET_BAD_PORT`, `EADDRINUSE` and `ERR_SERVER_ALREADY_LISTEN` as Node
  does, and in the order Node asks in; `forever` remains unimplemented
- `effects/node/virtual`: a bind address is compared with its host lower-cased,
  so `LOCALHOST` and `localhost` are one address as they are on a host
- `effects/node/virtual`: `stat` answers `isFile: false` for a directory and
  `ENOENT` for an empty path
- `media/type`: `detectPath` gives the `Content-Type` a file name implies, from
  its extension
