- `web`: new `fjs web [root] [port]` command serving a directory over HTTP —
  `index.html` for directory paths, `Content-Type` by extension, and `400`,
  `404`, `405`, `413` and `500` for everything it cannot answer with a file
- `media/type`: `detectPath` gives the `Content-Type` a file name implies, from
  its extension
- `effects/node/virtual`: the runner implements `createServer` and `listen`,
  answering requests queued in `State` — `forever` remains unimplemented
