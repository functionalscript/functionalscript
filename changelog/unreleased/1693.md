- **BREAKING CHANGES:** `effects/node`: `Listen` takes the host to bind as a
  third, required argument — `listen(server, port, host)` — and answers an
  `IoResult`, so a bind failure comes back through the effect's channel instead
  of killing the process after the program has already reported success
- **BREAKING CHANGES:** `effects/node`: `FileStat` carries `isFile` beside
  `size`, so a caller can tell a regular file from a FIFO, a device or a socket
  before reading it — a read that reaches one never returns
- `web`: new `fjs web [root] [port]` command serving a directory over HTTP on
  `127.0.0.1` — `index.html` for a directory path, `Content-Type` by extension,
  `Content-Length` on every response, and `400`, `404`, `405`, `413` or `500`
  for anything it cannot answer with a file
- `web`: what it will not serve — dot-prefixed segments (`.env`, `.git/config`),
  entries that are not regular files, a `Host` other than `localhost`,
  `127.0.0.1` or `[::1]` (binding loopback does not stop DNS rebinding; only the
  `Host` check does), an authority carrying userinfo, and a target whose scheme
  is neither `http` nor `https`
- `web`: an absolute-form target is accepted per RFC 9112 §3.2.2 and the host it
  names is believed over the `Host` header; a `405` carries `Allow`; every
  response carries `X-Content-Type-Options: nosniff`; an empty `root` argument
  is the working directory rather than the file system root
- `web`: a target's percent escapes decode in linear time — 20,000 escapes in one
  target took 3 seconds of event loop per request and now take 0.1
- `effects/node`: an HTTP request body past the `Vec` cap is answered `413`
  without reaching the listener, a listener that throws answers `500`, and both
  close the connection since neither read the request to its end; either used to
  end the whole server process through an unhandled rejection
- `effects/node`: a request body arriving as many small chunks is read in linear
  time — refusing 20,000 one-byte chunks took 2.8 seconds of event loop and now
  takes 0.17
- `effects/node`: a `listen` that fails, by event or synchronously, removes its
  handlers before rejecting, so a retry loop leaks none
- `effects/node/virtual`: the runner implements `createServer` and `listen`,
  answering requests queued in `State`. `listen` dispatches through the `Server`
  handle it was given and reports `ERR_SOCKET_BAD_PORT`, `EADDRINUSE` and
  `ERR_SERVER_ALREADY_LISTEN` as the Node runner does — port `0` names no port,
  so two servers asking for a free one do not collide; `forever` remains
  unimplemented
- `effects/node/virtual`: `stat` answers `isFile: false` for a directory or
  other non-regular entry, as a host does, and `ENOENT` for an empty path
- `media/type`: `detectPath` gives the `Content-Type` a file name implies, from
  its extension
