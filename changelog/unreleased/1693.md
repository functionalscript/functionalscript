- **BREAKING CHANGES:** `effects/node`: `Listen` takes the host to bind as a
  third, required argument — `listen(server, port, host)`. Node's own
  `listen(port)` binds every interface, so the address a server accepts on is
  now something a program states rather than something it inherits
- `web`: new `fjs web [root] [port]` command serving a directory over HTTP on
  `127.0.0.1` — `index.html` for directory paths, `Content-Type` by extension,
  `Content-Length` on every response, and `400`, `404`, `405`, `413` and `500`
  for everything it cannot answer with a file
- `media/type`: `detectPath` gives the `Content-Type` a file name implies, from
  its extension
- `effects/node/virtual`: the runner implements `createServer` and `listen`,
  answering requests queued in `State` — `forever` remains unimplemented
