- **BREAKING CHANGES:** `ci`: the exported `NixJob` declarations `denoNixJob`,
  `bunNixJob` and `wasmNixJob` are gone, and `nodeNixJobs` no longer carries the
  default Node version. The jobs those described now enter one shared shell, so
  `nixJobs` is three flakes rather than seven — `dev`, `node22` and `node24`.
  `wasmRust` and `wasmPackages` replace `wasmNixJob` for a caller that wanted
  the toolchain or the runtime attributes.
- **BREAKING CHANGES:** `ci`: the shared shell is generated to `nix/` itself
  rather than to a directory under it, so `flakePath` and `runPath` return
  `./nix` and `./nix/run` for it. A developer types `nix develop ./nix`, and
  `./nix/dev` no longer exists.
- `ci`: every canonical job but Node 22 and Node 24 runs its commands in the
  generated developer shell, `nix/`, rather than in a flake of its own. A
  command that names its runtime — `deno task cov`, `bun test`, `cargo test`,
  `tsc` — cannot be served the wrong one by what else is installed, so those
  jobs share; `npm ci` and `node --test` take whichever `node` reaches `PATH`
  first, so the two older Node versions keep a shell holding the single release
  each exists to test. CI now proves the environment developers work in.
- `ci`: the `dev` job is gone, leaving 13 jobs. It existed because nothing else
  entered that flake; four jobs now enter it on every pull request, and between
  them still assert all six versions it provides.
- `ci`: the generated `run` scripts name their flake's path rather than deriving
  it from `$0`, and pass `--quiet` three times instead of once. Nix's verbosity
  is a single integer that each `--quiet` decrements, so three is what it takes
  to get below warnings and silence `not writing modified lock file`, which
  these flakes emit on every step of every Nix job. It silences every other Nix
  warning too; `fjs/ci/todo/generated-flake-lock.md` owns generating a
  `flake.lock`, which would remove the warning at its source and take two of
  these flags back off with it.
- **BREAKING CHANGES:** `ci`: `basicNode` is removed. It built a Node install
  followed by extra steps, which was the shape a job had before it entered a
  flake; nothing has called it since, and the platform matrix — its last
  relative — no longer installs dependencies either.
- `ci`: the six platform jobs no longer run `npm ci`. They exercise a published
  FunctionalScript against this working tree, and the tree has nothing to
  install: no runtime dependency, and one `devDependency` that is types and so
  is never loaded. The step used to bring the compiler; that moved to the
  flakes.
