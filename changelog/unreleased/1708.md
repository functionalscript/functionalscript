- **BREAKING CHANGES:** `types/rtti/ts`: `Ts<T>` renders a tuple schema's
  **trailing** positions whose sets admit `undefined` as optional —
  `Ts<[number, bigint, option(boolean), option(string)]>` is now
  `readonly[number, bigint, (boolean|undefined)?, (string|undefined)?]` rather
  than a required-length tuple. This is the rule `StructTs` already applied per
  key, and it matches what `parse` and `validate` accept: an array may stop at
  the last required position. Only the trailing run, since TypeScript forbids a
  required element after an optional one, so an interior such position stays
  required with `undefined` in its type. A hand-written type pinned against
  `Ts<T>` for a tuple schema with trailing optional positions needs the `?`.
