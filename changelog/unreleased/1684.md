- **BREAKING CHANGES:** `djs/parser`'s `parseFromTokens` now requires exactly
  one final `eof` token, rejecting a stream missing one or holding two, which it
  used to accept. Only hand-built streams are affected — the tokenizer always
  emits exactly one.
- `djs/parser`: an unexpected `import` after a `const` now reports
  `unexpected token`, and an empty stream `missing end-of-input token`, at the
  same positions as before.
