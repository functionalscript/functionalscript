- **BREAKING CHANGES:** `djs`: the parser reads FunctionalScript modules only.
  A statement begins with `import`, `const`, or `export` and never with a
  value, so a JSON document no longer parses as a module; imports come before
  constants, and `export default` is required and last
- **BREAKING CHANGES:** `djs`: `fjs compile` reads a `.json` input with
  `fjs/media/json` instead of the module parser, so a `.json` file is JSON and
  nothing more — no `bigint`, `undefined`, comments, or identifier keys — and
  it cannot be imported until the language has `with { type: "json" }`. The
  `parser` export `parseJsonFromTokens` is gone with it
- `djs`: an error with no token to point at names the file being compiled
  instead of printing `undefined:undefined:undefined`
