- **BREAKING CHANGES:** `rtti`: `option` is a nullary schema denoting
  **absence** — a member that may be omitted is `or(option, t)`, and `{}` is
  no longer the same set as `{ a: undefined }`. The old `option(t)` set is
  `or(option, t, undefined)`; plain `or(option, t)` rejects a present
  `undefined`.
- `rtti`: `parse` omits an absent member — the struct kind drops the key,
  the array kind keeps holes and shortens a trailing absent run — so an
  optional member survives a JSON round-trip.
- `rtti`: `unknown` excludes absence, so a member declared `unknown` is
  required and the omittable top is `or(option, unknown)`. `Ts<>`, the
  runtime printer and `toJsonSchema` derive optionality (`?`, `required`,
  `minItems`) from absence — exact under `exactOptionalPropertyTypes`.
- `rtti`: a `Phantom` annotation on a schema whose root admits absence
  carries the new `Absent` marker, pinned with the new `CheckRaw`.
