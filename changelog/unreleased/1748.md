- **BREAKING CHANGES:** `rtti`: `option` is a nullary schema denoting
  **absence** — an omittable member is `or(option, t)`, which rejects a
  present `undefined`; the old `option(t)` set is `or(option, t, undefined)`.
  `{}` and `{ a: undefined }` are distinct sets.
- `rtti`: `parse` omits an absent member — the struct kind drops the key,
  the array kind keeps holes and shortens a trailing absent run — so an
  optional member survives a JSON round-trip.
- `rtti`: `unknown` excludes absence — the omittable top is
  `or(option, unknown)`. `Ts<>`, the runtime printer and `toJsonSchema`
  derive optionality (`?`, `required`, `minItems`) from absence, exact under
  `exactOptionalPropertyTypes`.
- `rtti`: a `Phantom` annotation on a schema whose root admits absence
  carries the new `Absent` marker, pinned with the new `CheckRaw`.
